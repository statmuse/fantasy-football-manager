# Any other platform

For a platform without a guide here (CBS, NFL Fantasy, Fleaflicker, MFL and others), work through the website in the browser while the owner is logged in.

1. Ask for the league URL. Open it and find: league settings (scoring, lineup slots, waivers, trade deadline), the owner's roster, this week's matchup, and the free agent list with projections.
2. Prefer reading page text over screenshots. If the site has a public read API, use it for reads, but never ask for or store passwords, tokens or cookies.
3. On the first move of each kind (lineup swap, add/drop, waiver claim, trade), take it slowly: confirm the page, make the move, then re-read the page to verify it landed.
4. Write what you learned into a new file here (`references/<platform>.md`), in the same shape as the other guides, so the next run is faster.

No browser tool? Run in advisor mode: do the StatMuse research, then give the owner a short list of moves to make themselves, each with the stat behind it.
